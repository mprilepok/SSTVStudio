# SSTV Studio — User Manual

SSTV Studio sends and receives slow-scan television (SSTV) pictures from a Windows PC. It controls your transceiver
through **Hamlib rigctld** and logs QSOs to **Wavelog**.

This manual describes version 1.0.0. The version you have is shown under **ⓘ** (About).

> 📷 **Screenshot [S1]** `images/s01-main-window.png`: the whole window on the **Receive** tab while a picture comes
> in. The picture is half drawn, the waterfall shows the signal between the markers, and the tuning line is green.
> This is the "hero" picture for the top of the manual and the README.
